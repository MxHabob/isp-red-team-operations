# Mission Model

## Lifecycle

1. Authorization and scope
2. Threat model and hypotheses
3. Environment preparation
4. Baseline
5. Controlled scenario execution
6. Telemetry collection
7. Evidence validation
8. Analysis
9. Finding review
10. Reporting
11. Remediation
12. Retest
13. After-action review

## Mission success

A mission succeeds when each approved hypothesis has a reproducible result, sufficient evidence, explicit limitations, and a documented disposition.

## Mission IDs

Use stable IDs such as:

- `RT-YNET-001` — operation
- `NET-001` — network test
- `DNS-001` — DNS test
- `TLS-001` — TLS test
- `ACC-001` — accounting test
- `MON-001` — monitoring test
- `EV-ACC-001-001` — evidence item
- `F-ACC-001` — finding
